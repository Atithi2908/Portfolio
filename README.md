## 🚀 Overview

This repository houses the Phase 1 technical portfolio for **Atithi Jaiman**, built with **Next.js (App Router, React 18, TypeScript)** and **Tailwind CSS**.

### Key Architectural Highlights:
- **Zero-Bloat Structured Data Layer (`src/data/`)**: All case studies, experience metrics, categorized skills, and profile details are maintained in structured data modules, enabling seamless RAG vector indexing in Phase 3.
- **Deep Technical Case Studies**:
  - **NEXA**: 5-layer autonomous AI agent with cyclic LangGraph state machine, dual UI perception (Playwright + Windows UI Automation), and Qdrant memory grounding.
  - **Distributed Backend Monitoring System**: Sub-millisecond async SDK, RabbitMQ message buffering, worker ingestion pools, threshold alert engine with Slack webhooks, and Docker/Jenkins CI/CD on AWS.
  - **TradeInCase**: Sub-second virtual trading engine with Redis in-memory order matching, full-duplex WebSockets, and Azure VM containerization.
- **Impact-Driven Experience**: Production deliverables at **Trivion Technologies** (audio processing pipeline via FFmpeg, Deepgram STT, automated LLM LinkedIn post generator, and duplicate-preventing background workers).
- **Categorized Skills**: Organized into AI & Autonomous Systems, Backend Infrastructure, Databases & Vector Stores, DevOps/Cloud, and Languages.
- **Algorithmic Rigor & Achievements**: LeetCode Knight (1850+ rating, Top 5%), CodeChef 3★ (1665 rating), AWS Educate Cloud 101 Certified.
- **Speaking Avatar Stage (Phase 2 Ready)**: Dedicated visual container and audio-waveform indicator slot configured in the Hero section.
- **Working Contact Form & Direct Actions**: Functional mailto generator, single-click email copier with toast confirmation, and direct social links.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel / Netlify

1. Push this repository to GitHub: `https://github.com/Atithi2908/Aj_Portfolio`
2. Import project in [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. The build command `next build` will automatically generate the fast static production site.
